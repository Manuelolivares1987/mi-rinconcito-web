Configuración de GitHub

Conecta con GitHub para publicar cambios automáticamente

Una vez configurado, podrás publicar cambios con un solo clic

Paso 1: Crear repositorio en GitHub

1

Ve a github.com/new

Nombre del repositorio: mi-rinconcito-web

Marca "Public" y clic en "Create repository"

Paso 2: Crear Token de Acceso

2

Ve a github.com/settings/tokens/new

Nombre: Mi Rinconcito Admin

Marca los permisos: repo (todos)

Clic en "Generate token" y copia el token

Paso 3: Configurar conexión

El token se guarda solo en tu navegador
